# FDS_RECORD
This repository contains 20 experiments for Fundamentals of Data Science (FDS), implemented and executed in Google Colab.

experiments details:
1. **Experiment 1.a:** Basic of pandas
2. **Experiment 1.b:** Analyze the trend of data science job postings over the last decade for the given data on the number of data science job postings each year. Use pandas for data manipulation and matplotlib/seaborn for visualization.
3. **Experiment 1.c:** Analyze and visualize the distribution of various data science roles (Data Analyst, Data Engineer, Data Scientist, etc.) from a dataset.
4. **Experiment 1.d:** Conduct an experiment to differentiate Structured, Un-structured and Semi structured data based on datasets given.
5. **Experiment 1.e:** Conduct an experiment to encrypt and decrypt given sensitive data using the cryptography library fernet.
6. **Experiment 2:** Upload and analyze the dataset given in CSV format and perform data preprocessing and visualization.
7. **Experiment 3.a:** Conduct an experiment to show data visualization using line plot.
8. **Experiment 3.b:** Conduct an experiment to show data visualization using bar chart.
9. **Experiment 3.c:** Conduct an experiment to show data visualization using pie chart.
10. **Experiment 4:** Count the frequency of occurrence of a word in a body of text (needed during text processing).
11. **Experiment 5:** Data Collection and Initial Exploration.
12. **Experiment 6:** Time Series Analysis of Website Traffic.
13. **Experiment 7:** Random Sampling and Sampling Distribution.
14. **Experiment 8:** Conduct Z-test for the data given using Python.
15. **Experiment 9:** Experiment to understand Matplotlib library use cases in Data Science through visualization.
16. **Experiment 10:** Experiment to understand array function in Data Science.
17. **Experiment 11:** Experiment to understand Pandas library use cases in Data Science.
18. **Experiment 12:** Experiment to detect outliers in a given dataset.
19. **Experiment 13:** Experiment to handle missing values and inappropriate data in a given dataset.
20. **Experiment 14:** Experiment to understand feature scaling.
21. **Experiment 15:** Experiment to understand the data preprocessing in Data Science.
22. **Experiment 16:** Experiment to understand EDA - Quantitative and Qualitative analysis.
23. **Experiment 17:** Experiment to understand Linear Regression for a given dataset.
24. **Experiment 18:** Experiment to understand KNN algorithm for a given dataset.
25. **Experiment 19:** Experiment to understand Logistic Regression for a given dataset.
26. **Experiment 20:** Experiment to understand K-means clustering algorithm for a given dataset.
